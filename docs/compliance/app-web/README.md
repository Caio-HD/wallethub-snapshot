## Requisitos e notas preliminares

- **LGPD / UX:** transparência, cookies e tecnologias similares (se usadas), formulários e mensagens de erro sem dados sensíveis em texto.
- **Acessibilidade:** alinhamento a boas práticas e requisitos legais aplicáveis ao canal web (referências oficiais a arquivar quando a auditoria for feita).
- **Segurança no cliente:** armazenamento de tokens, headers (`X-Organization-Id`), e não expor dados em logs do browser.
